## 4. Finding F6 — CI's mismatch flow check is broken and hidden

`pdk_validation/regression/run_mc.py --axis mm` compares measured pair σ against an "intended" σ it
computes itself. Its CI step is `continue-on-error`, so the step and job report success regardless.
The failure predates this program.

| quantity | value |
|---|---|
| test bench | two NMOS50, W = 10 µm, L = 1 µm, Vgs = 2 V, Vds = 3 V; empirical gm/Id 1.686 V⁻¹ |
| coefficient hardcoded in the test | `DVTH_3SIG_BASE = 0.0135` V·µm |
| coefficient in the wrapper since `dc7de19` (O5 A_VT widening, 2026-07-24) | 0.033 V·µm (2.44×) |
| measured σ(log I1/I2), N = 80 / N = 400 | 1.078 % / 1.014 % |
| intended, as coded | 0.364 % (N = 400: measured ÷ intended = 2.79×) |
| intended, with the current coefficient | 0.839 % (Vth term 0.829 %, W/L term 0.130 %, RSS) |
| gap remaining after the correction | +21 %, about 6 standard errors at N = 400 — **not sampling noise; cause unknown** |

The stale coefficient explains most of the gap. I did not investigate the residual: this stop is for
review, and Phase 3's sensitivity mode is the natural tool, since it decomposes σ per term.
